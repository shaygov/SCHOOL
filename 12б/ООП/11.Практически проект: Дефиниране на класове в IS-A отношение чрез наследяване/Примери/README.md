# Практически проект: Дефиниране на класове в IS-A отношение чрез наследяване

## Описание на проекта

Този проект демонстрира използването на наследяване в C# за създаване на система за управление на библиотека. Проектът включва йерархия от класове, които представят различни типове документи.

## Структура на проекта

### Базов клас
- **Document.cs** - Базов клас за всички документи в библиотеката

### Производни класове
- **Book.cs** - Книги с автор, ISBN, брой страници
- **Magazine.cs** - Списания с номер, дата, издател
- **Newspaper.cs** - Вестници с дата, тираж, език
- **Thesis.cs** - Дипломни работи с университет, ръководител

### Система за управление
- **LibraryManager.cs** - Клас за управление на библиотеката
- **Program.cs** - Главна програма с демонстрация

## IS-A отношения

```
Document (базов клас)
├── Book IS-A Document
├── Magazine IS-A Document
├── Newspaper IS-A Document
└── Thesis IS-A Document
```

### На Linux/macOS:

```

```

```bash

```

## Функционалности

1. **Създаване на документи** - различни типове документи
2. **Заемане и връщане** - система за проследяване на заети документи
3. **Търсене** - по заглавие и тип документ
4. **Статистики** - информация за библиотеката
5. **Полиморфизъм** - демонстрация на различни поведения

## Ключови принципи

- **Наследяване** - преизползване на код от базовия клас
- **Полиморфизъм** - различни имплементации на същите методи
- **Инкапсулация** - скриване на вътрешната реализация
- **IS-A отношения** - логическо групиране на свързани класове

## Примери за използване

```csharp
// Създаване на книга
Book book = new Book("Програмиране на C#", 2023, "Секция А1", 
                     "Иван Петров", "978-954-123-456-7", 450, "Техническа литература");

// Полиморфно използване
Document doc = new Book("История", 2022, "Секция Б2", 
                        "Автор", "ISBN", 300, "История");

// Извикване на специфични методи
if (doc is Book bookDoc) {
    bookDoc.Read();
    Console.WriteLine(bookDoc.GetReadingTime());
}
```
