  Въпрос 12:
    Обяснение на наблюдение на процеси и памет:
      - ps / top или Task Manager за процесите
      - free, vmstat, /proc/meminfo за паметта
    
    ПОДРОБЕН ОТГОВОР:
    За наблюдение на процесите в Linux се използват командите ps и top. Командата ps показва 
    списък с текущите процеси с информация за PID (Process ID), потребителя, използване на 
    CPU и памет. Командата top показва процесите в реално време с динамично обновяване. 
    В Windows се използва Task Manager (Диспечер на задачите), който показва процеси, 
    използване на CPU, памет и други ресурси.
    
    За наблюдение на паметта в Linux се използват командите free (показва обща, използвана 
    и свободна памет), vmstat (статистика за памет, CPU и I/O), и cat /proc/meminfo 
    (подробна информация за използването на паметта). Тези инструменти помагат да се 
    идентифицират процеси, които използват много памет или CPU ресурси.

  Въпрос 13:
    Обяснение на основни команди за файлове и директории (cd, ls/dir, mkdir, cp/copy, mv/move, rm/del)
    + примери за използването им.
    
    ПОДРОБЕН ОТГОВОР:
    Основните команди за работа с файлове и директории са:
    
    - cd (change directory) - променя текущата директория
      Пример: cd /home/user/Documents
    
    - ls (Linux) / dir (Windows) - показва съдържанието на директория
      Пример: ls -l (показва подробна информация)
    
    - mkdir - създава нова директория
      Пример: mkdir myfolder
    
    - cp (Linux) / copy (Windows) - копира файлове
      Пример: cp file.txt /backup/file.txt
    
    - mv (Linux) / move (Windows) - премества или преименува файлове
      Пример: mv oldname.txt newname.txt
    
    - rm (Linux) / del (Windows) - изтрива файлове
      Пример: rm file.txt

  Въпрос 14:
    Обяснение за създаване на потребители и групи, права за достъп
    + пример за проблем при неправилни права.
    
    ПОДРОБЕН ОТГОВОР:
    Създаването на потребители и групи в операционна система позволява управление на достъпа 
    до ресурси. В Linux се използват командите useradd (създаване на потребител) и groupadd 
    (създаване на група). Правата за достъп се управляват с chmod (промяна на права) и chown 
    (промяна на собственик).
    
    Важно е да се задават подходящи права, защото неправилните права могат да доведат до 
    проблеми със сигурността. Например, ако файл с пароли има права за четене за всички 
    потребители (chmod 644), всеки потребител в системата може да прочете паролите, което 
    е сериозен проблем със сигурността. Правилното решение е файлът да има права само за 
    собственика (chmod 600).

  Въпрос 12:
    Описание как се създава и изпълнява прост shell скрипт (bash или PowerShell).
    
    ПОДРОБЕН ОТГОВОР:
    За създаване на shell скрипт в Linux (bash) се изпълняват следните стъпки:
    1. Създаване на файл с разширение .sh (например script.sh)
    2. Добавяне на shebang на първия ред: #!/bin/bash
    3. Добавяне на команди в скрипта
    4. Задаване на права за изпълнение: chmod +x script.sh
    5. Стартиране: ./script.sh
    
    Пример bash скрипт:
    #!/bin/bash
    echo "Здравейте!"
    date
    
    В PowerShell (Windows):
    1. Създаване на файл с разширение .ps1
    2. Добавяне на команди
    3. Стартиране: powershell -ExecutionPolicy Bypass -File script.ps1

  Въпрос 13:
    Обяснение как се управляват правата за достъп до файлове и директории с командите chmod и chown в Linux
    + примери за използване на тези команди
    + обяснение на различните права за достъп (read, write, execute).
    
    ПОДРОБЕН ОТГОВОР:
    Командата chmod променя правата за достъп до файлове и директории. Правата се задават 
    за три групи: собственик (owner), група (group) и други (others). Всяка група може да 
    има права за четене (read - r), писане (write - w) и изпълнение (execute - x).
    
    Примери:
    - chmod 755 file.txt - собственикът има всички права (rwx), групата и другите имат 
      права за четене и изпълнение (r-x)
    - chmod 644 file.txt - собственикът има права за четене и писане (rw-), групата и 
      другите само четене (r--)
    - chmod +x script.sh - добавя право за изпълнение за всички
    
    Командата chown променя собственика и/или групата на файл:
    - chown user:group file.txt - променя собственика и групата
    - chown user file.txt - променя само собственика

  Въпрос 14:
    Инсталиране на софтуер чрез пакетен мениджър (apt, yum, winget и др.)
    + примерна команда и обяснение на частите ѝ.
    
    ПОДРОБЕН ОТГОВОР:
    Пакетните мениджъри позволяват лесно инсталиране, актуализиране и премахване на софтуер.
    
    В Debian/Ubuntu се използва apt:
    - sudo apt update - обновява списъка с налични пакети
    - sudo apt install package-name - инсталира пакет
    Пример: sudo apt install vim
      * sudo - изпълнява командата с административни права
      * apt - пакетният мениджър
      * install - команда за инсталиране
      * vim - името на пакета за инсталиране
    
    В Red Hat/CentOS се използва yum:
    - sudo yum install package-name
    
    В Windows се използва winget:
    - winget install PackageName
    Пример: winget install Microsoft.VisualStudioCode
