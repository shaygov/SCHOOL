Подготвителни материали по C# - Въведение в програмирането

1. C# Въведение

C# е модерен, обектно-ориентиран език за програмиране, разработен от Microsoft. Използва се за създаване на различни типове приложения: уеб, десктоп, мобилни и игри.

  • Синтаксис: Подобен на Java и C++
  • Платформа: .NET Framework
  • Тип: Статично типизиран език
  • Парадигма: Обектно-ориентирано програмиране

2. Първа програма - Hello World

using System;

class Program {
    static void Main() {
        Console.WriteLine("Hello World!");
    }
}

Обяснение:

  • using System; - включва системната библиотека
  • class Program - дефинира клас с име Program
  • static void Main() - начална точка на програмата
  • Console.WriteLine() - извежда текст в конзолата

3. C# Синтаксис

Основни правила:

  • Всяка команда завършва с ; (точка и запетая)
  • Блоковете код се ограждат с {} (фигурни скоби)
  • Чувствителен е към малки/големи букви (case-sensitive)
  • Коментарите: // за един ред, /* */ за няколко реда
// Това е коментар на един ред
/* Това е
   коментар на
   няколко реда */

class Example {
    static void Main() {
        Console.WriteLine("Пример");
    }
}

4. C# Изход (Output)

Console.WriteLine() - извежда текст и преминава на нов ред

Console.Write() - извежда текст без да преминава на нов ред

using System;

class Program {
    static void Main() {
        Console.WriteLine("Първи ред");
        Console.WriteLine("Втори ред");
        Console.Write("Текст на ");
        Console.Write("същия ред");
    }
}

Резултат:

Първи ред
Втори ред
Текст на същия ред

6. C# Променливи (Variables)

Променливата е контейнер за съхранение на данни. В C# трябва да декларираме типа преди да използваме променливата.

using System;

class Program {
    static void Main() {
        // Деклариране и инициализация
        string name = "Иван";
        int age = 15;
        double height = 1.75;
        
        // Деклариране, след това присвояване
        int number;
        number = 10;
        
        // Множествена декларация
        int x = 5, y = 10, z = 15;
        
        Console.WriteLine($"Име: {name}, Възраст: {age}");
    }
}

Правила за имена на променливи:

  • Започват с буква или _
  • Могат да съдържат букви, цифри и _
  • Не могат да съдържат интервали
  • Не могат да са запазени думи (int, string, class и др.)

8. C# Преобразуване на типове (Type Casting)

Има два вида преобразуване:

  • Имплицитно (автоматично) - от по-малък към по-голям тип
  • Експлицитно (ръчно) - от по-голям към по-малък тип
// Имплицитно преобразуване
int myInt = 9;
double myDouble = myInt;  // Автоматично: int → double

// Експлицитно преобразуване
double myDouble2 = 9.78;
int myInt2 = (int)myDouble2;  // Ръчно: double → int (резултат: 9)

// Преобразуване с методи
string numberText = "123";
int number = int.Parse(numberText);  // string → int
int number2 = Convert.ToInt32(numberText);  // Алтернативен метод

// Преобразуване на числа в текст
int age = 15;
string ageText = age.ToString();  // int → string

9. C# Потребителски вход (User Input)

Console.ReadLine() - чете ред от конзолата и връща string

Console.ReadKey() - чете един символ и чака натискане на клавиш

using System;

class Program {
    static void Main() {
        // Четене на текст
        Console.Write("Въведете вашето име: ");
        string name = Console.ReadLine();
        
        // Четене на число
        Console.Write("Въведете вашата възраст: ");
        int age = int.Parse(Console.ReadLine());
        
        // Четене на десетично число
        Console.Write("Въведете цена: ");
        double price = double.Parse(Console.ReadLine());
        
        // Извеждане на резултата
        Console.WriteLine($"Здравей, {name}! Ти си на {age} години.");
        Console.WriteLine($"Цената е {price} лева.");
        
        Console.WriteLine("\nНатисни клавиш за изход...");
        Console.ReadKey();
    }
}

12. C# Низове (Strings)

String е последователност от символи. В C# strings са неизменими (immutable).

string firstName = "Иван";
string lastName = "Петров";
string fullName = firstName + " " + lastName;  // Конкатенация
Console.WriteLine(fullName);  // Иван Петров

// Дължина на низ
int length = fullName.Length;  // 11

// Доступ до символи
char firstChar = fullName[0];  // 'И'

// Методи за работа със strings
string text = "Hello World";
Console.WriteLine(text.ToUpper());      // HELLO WORLD
Console.WriteLine(text.ToLower());      // hello world
Console.WriteLine(text.Substring(0, 5)); // Hello
Console.WriteLine(text.IndexOf("World")); // 6

// Интерполация на низове
string name = "Мария";
int age = 15;
string message = $"Име: {name}, Възраст: {age}";
Console.WriteLine(message);  // Име: Мария, Възраст: 15

Основни string методи:

  • Length - дължина на низа
  • ToUpper() - преобразува в главни букви
  • ToLower() - преобразува в малки букви
  • Substring(start, length) - извлича подниз
  • IndexOf(text) - намира позиция на текст
  • Replace(old, new) - замества текст
  • Contains(text) - проверява дали съдържа текст

13. C# Булеви стойности (Booleans)

bool типът може да има само две стойности: true или false.

bool isStudent = true;
bool isAdult = false;

// Булеви изрази
int age = 15;
bool canVote = age >= 18;  // false

// Логически операции
bool result1 = true && false;   // false (И)
bool result2 = true || false;    // true (ИЛИ)
bool result3 = !true;            // false (НЕ)

// Използване в условия
if (isStudent) {
    Console.WriteLine("Ти си студент");
}

14. C# Условия (If...Else)

Условията позволяват на програмата да взема решения въз основа на различни ситуации.

If изявление

int age = 15;

if (age >= 18) {
    Console.WriteLine("Ти си пълнолетен");
}

If-Else изявление

int age = 15;

if (age >= 18) {
    Console.WriteLine("Ти си пълнолетен");
} else {
    Console.WriteLine("Ти си непълнолетен");
}

If-Else If-Else изявление

int grade = 85;

if (grade >= 90) {
    Console.WriteLine("Отличен");
} else if (grade >= 80) {
    Console.WriteLine("Много добър");
} else if (grade >= 70) {
    Console.WriteLine("Добър");
} else if (grade >= 60) {
    Console.WriteLine("Среден");
} else {
    Console.WriteLine("Слаб");
}

Тернарен оператор (кратък if-else)

int age = 15;
string status = (age >= 18) ? "Пълнолетен" : "Непълнолетен";
Console.WriteLine(status);  // Непълнолетен

Switch изявление

int day = 3;
string dayName;

switch (day) {
    case 1:
        dayName = "Понеделник";
        break;
    case 2:
        dayName = "Вторник";
        break;
    case 3:
        dayName = "Сряда";
        break;
    default:
        dayName = "Невалиден ден";
        break;
}

Console.WriteLine(dayName);  // Сряда

15. Практически примери

Пример 1: Калкулатор

using System;

class Program {
    static void Main() {
        Console.Write("Въведете първо число: ");
        double num1 = double.Parse(Console.ReadLine());
        
        Console.Write("Въведете второ число: ");
        double num2 = double.Parse(Console.ReadLine());
        
        Console.WriteLine($"{num1} + {num2} = {num1 + num2}");
        Console.WriteLine($"{num1} - {num2} = {num1 - num2}");
        Console.WriteLine($"{num1} * {num2} = {num1 * num2}");
        Console.WriteLine($"{num1} / {num2} = {num1 / num2:F2}");
    }
}

Пример 2: Проверка на възраст

using System;

class Program {
    static void Main() {
        Console.Write("Въведете възраст: ");
        int age = int.Parse(Console.ReadLine());
        
        if (age >= 18) {
            Console.WriteLine("Пълнолетен - можеш да гласуваш");
        } else {
            Console.WriteLine($"Непълнолетен - остават {18 - age} години до пълнолетие");
        }
    }
}

Пример 3: Работа със strings

using System;

class Program {
    static void Main() {
        Console.Write("Въведете вашето име: ");
        string name = Console.ReadLine();
        
        Console.WriteLine($"Дължина на името: {name.Length} символа");
        Console.WriteLine($"Име с главни букви: {name.ToUpper()}");
        Console.WriteLine($"Име с малки букви: {name.ToLower()}");
        
        if (name.Contains("а")) {
            Console.WriteLine("Името съдържа буквата 'а'");
        }
    }
}

17. Често срещани грешки

  • Забравена точка и запетая: Всяка команда трябва да завършва с ;
  • Неправилни кавички: Strings използват ", chars използват '
  • Case-sensitive: Console не е същото като console
  • Недекларирана променлива: Винаги декларирай променливата преди употреба
  • Несъвместими типове: Не може да присвоиш string на int без преобразуване
  • Липсващи скоби: Условията и методите трябва да имат ()

18. Полезни съвети

  • Винаги използвай смислени имена на променливи
  • Добавяй коментари за обяснение на сложен код
  • Тествай програмата с различни входни данни
  • Проверявай за възможни грешки (например деление на нула)
  • Използвай интерполация на низове ($"...") за по-четим код
  • Практикувай редовно с различни задачи
