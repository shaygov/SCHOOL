Раздел 5 — Подпрограми (функции / методи)

Параметри, връщана стойност, цикли for и while · 8б клас · Въведение в програмирането (ИУЧ – РПП)

🔧 Кодът, който можеш да извикаш отново

Вместо да копираш един и същ код на много места, го описваш веднъж в подпрограма (метод) и го използваш колкото пъти искаш.

Аналогия от ежедневието

  • Рецепта — методът е рецептата; Main казва „направи борщ“.
  • Съставки — параметрите (колко картофи, колко месо).
  • Готовото ястие — връщаната стойност (return).
  • Цикъл — повтаряш една и съща стъпка N пъти (напр. разбъркване 10 пъти).

1. Какво е подпрограма (метод)?

Подпрограма (в C# се нарича метод) е именуван блок от код, който изпълнява конкретна задача. Може да се извика многократно от различни места в програмата.

В C# методите се дефинират вътре в клас. Методът Main е началната точка — от него започва изпълнението.

Структура на метод

[модификатор] [тип_на_връщане] ИмеНаМетода([параметри]) {
    // тяло на метода
    return стойност; // ако типът не е void
}
Част Пример Обяснение
Тип на връщане int, void Какъв резултат връща методът. void = без резултат.
Име Sum, PrintTable Описателно име с главна буква (PascalCase).
Параметри int a, int b Данни, които методът получава при извикване.
Тяло { ... } Командите, които се изпълняват.

Метод без връщане на стойност — void

Методът извършва действие, но не връща резултат:

using System;

class Program {
    static void Main() {
        SayHello();           // извикване на метода
        SayHelloTo("Иван");   // с параметър
    }

    static void SayHello() {
        Console.WriteLine("Здравей!");
    }

    static void SayHelloTo(string name) {
        Console.WriteLine($"Здравей, {name}!");
    }
}

Изход:

Здравей!
Здравей, Иван!

Метод с връщане на стойност

Методът изчислява нещо и го връща с return:

using System;

class Program {
    static void Main() {
        int result = Add(3, 5);
        Console.WriteLine($"3 + 5 = {result}");

        double area = RectangleArea(4, 6);
        Console.WriteLine($"Площ: {area}");
    }

    static int Add(int a, int b) {
        return a + b;
    }

    static double RectangleArea(double width, double height) {
        return width * height;
    }
}

Изход:

3 + 5 = 8
Площ: 24
Запомни:
  • Формални параметри — имената в дефиницията на метода (int a, int b).
  • Актуални параметри (аргументи) — стойностите при извикване (Add(3, 5)).
  • След return методът приключва — кодът под него не се изпълнява.
  • Типът след return трябва да съвпада с типа на метода.

2. Параметри и връщана стойност — примери

Пример 1: Проверка дали число е четно

static bool IsEven(int number) {
    return number % 2 == 0;
}

static void Main() {
    Console.WriteLine(IsEven(4));   // True
    Console.WriteLine(IsEven(7));   // False
}

Пример 2: По-голямото от две числа

static int Max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

static void Main() {
    Console.WriteLine(Max(10, 25));  // 25
}

Пример 3: Метод с няколко параметъра и изчисление

static double Average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

static void Main() {
    double avg = Average(6, 8, 10);
    Console.WriteLine($"Средно: {avg}");  // 8
}
Извикване на метод — стъпки:
  1. Програмата влиза в Main.
  2. При Max(10, 25) стойностите 10 и 25 се подават на параметрите a и b.
  3. Изпълнява се тялото на метода.
  4. return връща резултата обратно в Main, където може да се запише в променлива или изведе.

3. Цикъл for

Цикълът for се използва, когато знаем колко пъти искаме да повторим код.

for (инициализация; условие; стъпка) {
    // тяло — повтаря се
}

✅ Подходящ за

  • Броене от 1 до N
  • Обхождане на масив (по-късно)
  • Таблица на умножение

⚠️ Честа грешка

  • i < 5 → 0,1,2,3,4
  • i <= 5 → 0,1,2,3,4,5
  • Внимавай с границата!

Пример: Числа от 1 до 5

static void Main() {
    for (int i = 1; i <= 5; i++) {
        Console.WriteLine(i);
    }
}

Изход: 1, 2, 3, 4, 5 (всяко на нов ред)

Пример: Сумиране от 1 до N с метод

using System;

class Program {
    static void Main() {
        int n = 10;
        int sum = SumFrom1To(n);
        Console.WriteLine($"Сумата от 1 до {n} е {sum}");
    }

    static int SumFrom1To(int n) {
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum = sum + i;
        }
        return sum;
    }
}

Изход: Сумата от 1 до 10 е 55

Пример: Метод, който извежда таблица на умножение

static void PrintMultiplicationTable(int number) {
    for (int i = 1; i <= 10; i++) {
        Console.WriteLine($"{number} x {i} = {number * i}");
    }
}

static void Main() {
    PrintMultiplicationTable(7);
}

4. Цикъл while

Цикълът while повтаря код, докато условието е вярно. Броят повторения може да не е известен предварително.

while (условие) {
    // тяло
    // променяме нещо, за да не е безкраен цикъл!
}

🔄 for

Броят повторения е ясен още при писане на кода.

🔄 while

Повтаря се, докато условието е true. Ако е false в началото — тялото не се изпълнява изобщо.

Пример: Четни и нечетни числа от 1 до 10

static void PrintEvenOdd(int number) {
    if (number % 2 == 0) {
        Console.WriteLine($"{number} е ЧЕТНО");
    } else {
        Console.WriteLine($"{number} е НЕЧЕТНО");
    }
}

static void Main() {
    int number = 1;
    while (number <= 10) {
        PrintEvenOdd(number);
        number++;   // увеличаваме брояча
    }
}

Пример: Метод за броене на цифрите в число

static int CountDigits(int n) {
    if (n == 0) return 1;

    int count = 0;
    while (n > 0) {
        count++;
        n = n / 10;
    }
    return count;
}

static void Main() {
    Console.WriteLine(CountDigits(12345));  // 5
    Console.WriteLine(CountDigits(0));    // 1
}

Пример: Сумиране на въведени числа (до 0)

static int ReadAndSum() {
    int sum = 0;
    int input;

    Console.Write("Въведете число (0 за край): ");
    input = int.Parse(Console.ReadLine());

    while (input != 0) {
        sum = sum + input;
        Console.Write("Въведете число (0 за край): ");
        input = int.Parse(Console.ReadLine());
    }
    return sum;
}

static void Main() {
    int total = ReadAndSum();
    Console.WriteLine($"Обща сума: {total}");
}

5. Комбиниране: методи + цикли

Пример: Факториел с for

static long Factorial(int n) {
    long result = 1;
    for (int i = 1; i <= n; i++) {
        result = result * i;
    }
    return result;
}

static void Main() {
    Console.WriteLine($"5! = {Factorial(5)}");   // 120
    Console.WriteLine($"6! = {Factorial(6)}");   // 720
}

Пример: Проверка за просто число с while

static bool IsPrime(int n) {
    if (n < 2) return false;

    int divisor = 2;
    while (divisor * divisor <= n) {
        if (n % divisor == 0) {
            return false;
        }
        divisor++;
    }
    return true;
}

static void Main() {
    for (int i = 2; i <= 20; i++) {
        if (IsPrime(i)) {
            Console.Write($"{i} ");
        }
    }
    // Изход: 2 3 5 7 11 13 17 19
}

Пример: Пълен програмен шаблон

using System;

class Program {
    static void Main() {
        PrintHeader();
        ShowMenu();
    }

    static void PrintHeader() {
        Console.WriteLine("=== Калкулатор на сума ===");
    }

    static void ShowMenu() {
        Console.Write("До кое число да сумираме? ");
        int n = int.Parse(Console.ReadLine());
        int sum = CalculateSum(n);
        PrintResult(n, sum);
    }

    static int CalculateSum(int n) {
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        return sum;
    }

    static void PrintResult(int n, int sum) {
        Console.WriteLine($"1 + 2 + ... + {n} = {sum}");
    }
}

6. Обобщение

Понятие Ключова дума / синтаксис Кога се ползва
Метод без резултат static void Име() Извеждане, форматиране, меню
Метод с резултат static int Име() + return Изчисления, проверки
Параметри (int a, int b) Подаване на данни към метода
Цикъл for for (int i = 0; i < n; i++) Известен брой повторения
Цикъл while while (условие) Повтаряне докато условието е вярно
Често срещани грешки:
  • Забравен return в метод, който не е void.
  • Безкраен while — липсва промяна на променливата в условието.
  • Объркани граници в for: < срещу <=.
  • Извикване на метод без скоби: SayHello ❌ → SayHello() ✅
