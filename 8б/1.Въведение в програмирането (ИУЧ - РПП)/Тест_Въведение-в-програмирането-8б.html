Въпрос 1
Кое твърдение най-точно описва езика C#?
А) Скриптов език, който се изпълнява само в браузър
Б) Език за маркиране, използван за създаване на уеб страници
В) Модерен, обектно-ориентиран език за програмиране върху .NET платформа
Г) Език, който може да се използва само за игри и нищо друго
Правилен отговор: В) Модерен, обектно-ориентиран език за програмиране върху .NET платформа

C# е статично типизиран, обектно-ориентиран език, разработен от Microsoft и използван за различни видове приложения.

Въпрос 2
Кое е вярно за конзолната програма?
А) Задължително използва графични бутони и прозорци
Б) Работи в текстов режим – входът и изходът са текст в конзолен прозорец
В) Може да се стартира само от Visual Studio и не може самостоятелно
Г) Използва само мишка, без клавиатура
Правилен отговор: Б) Работи в текстов режим – входът и изходът са текст в конзолен прозорец

Конзолните програми нямат графичен интерфейс – комуникацията става чрез текст в прозореца на конзолата.

Въпрос 3
Коя редица правилно описва стандартната структура на проста конзолна програма на C#?
А) using System; → class Program { } → static void Main() { /* код */ }
Б) class Program { } → using System; → static void Code() { }
В) static void Main() { } → using System; → class Program { }
Г) using Main; → class Console { } → static void Program()
Правилен отговор: А) using System; → class Program { } → static void Main() { /* код */ }

Файлът започва с using директиви, след това клас, а вътре в него е методът Main, който е началната точка на програмата.

Въпрос 4
Кое от следните твърдения за метода Main е вярно?
А) Може да се казва произволно, например StartProgram
Б) Не е задължителен в конзолна програма
В) Винаги трябва да връща число
Г) Той е началната точка на изпълнение на програмата
Правилен отговор: Г) Той е началната точка на изпълнение на програмата

При стартиране на проекта, .NET изпълнява кода в метода Main.

Въпрос 5
Коя команда извежда текст и преминава на нов ред в конзолата?
А) Console.WriteLine("Текст");
Б) Console.Write("Текст")
В) Console.ReadLine("Текст")
Г) Console.Print("Текст");
Правилен отговор: А) Console.WriteLine("Текст");

WriteLine извежда текста и добавя нов ред, докато Write остава на същия ред.

Въпрос 6
Кое е типично използване на Console.ReadLine() в конзолна програма?
А) За изчистване на екрана
Б) За прочитане на въведен от потребителя текстов ред
В) За изчакване на произволен клавиш без да чете текста
Г) За промяна на цвета на конзолата
Правилен отговор: Б) За прочитане на въведен от потребителя текстов ред

Console.ReadLine() връща въведената от потребителя стойност като string, която често после се преобразува към число.

Въпрос 7

А) var int age = 15;

В) int age = 15;
Г) age int = 15;
Правилен отговор: В) int age = 15;

Първо се посочва типът, после името на променливата и по желание – начална стойност.

А) int
Б) double

string представлява последователност от символи и се използва за текст.

Въпрос 9
Искаме да прочетем възраст от конзолата като цяло число. Кой фрагмент е коректен?
А) int age = Console.ReadLine();
Б) int age = int.Parse(Console.ReadLine());
В) string age = int.Parse(Console.ReadLine());
Г) double age = Console.ReadInt();
Правилен отговор: Б) int age = int.Parse(Console.ReadLine());

Console.ReadLine() връща string, който се преобразува към int с int.Parse() или Convert.ToInt32().

Въпрос 10
Какъв ще е резултатът от израза 10 % 3 в C#?
А) 0
Б) 3
В) 1
Г) 7
Правилен отговор: В) 1

Операторът % връща остатъка от целочислено деление – 10 / 3 = 3 с остатък 1.

Въпрос 11
Кой логически оператор ще върне true само ако и двете условия са верни?
А) &&
Б) ||
В) !
Г) ==
Правилен отговор: А) &&

&& (логическо И) връща true само ако и двете условия са true.

Въпрос 12
Кое от следните е коректен if-else блок в C#?
А) if age >= 18: Console.WriteLine("Пълнолетен");
Б) if (age >= 18) { Console.WriteLine("Пълнолетен"); } else { Console.WriteLine("Непълнолетен"); }
В) if (age >= 18) then Console.WriteLine("Пълнолетен");
Г) if (age >= 18) Console.WriteLine("Пълнолетен") else Console.WriteLine("Непълнолетен")
Правилен отговор: Б) if (age >= 18) { ... } else { ... }

Условията в C# използват кръгли скоби за логическия израз и фигурни скоби за блок от команди.

Въпрос 13
Кой for-цикъл правилно извежда числата от 1 до 5 включително?
А) for (int i = 1; i < 5; i++) Console.WriteLine(i);
Б) for (int i = 0; i < 5; i++) Console.WriteLine(i);
В) for (int i = 5; i >= 1; i++) Console.WriteLine(i);
Г) for (int i = 1; i <= 5; i++) Console.WriteLine(i);
Правилен отговор: Г) for (int i = 1; i <= 5; i++) Console.WriteLine(i);

Започваме от 1, увеличаваме i с 1 и спираме, когато i стане по-голямо от 5.

Въпрос 14
Кое твърдение за while цикъл е вярно?
А) Винаги се изпълнява поне веднъж, независимо от условието
Б) Може да се използва само с числа
В) Проверява условието преди всяка итерация и може да не се изпълни нито веднъж
Г) Няма нужда от условие – спира сам
Правилен отговор: В) Проверява условието преди всяка итерация и може да не се изпълни нито веднъж

while цикълът първо проверява логическо условие; ако то е false още в началото, тялото няма да се изпълни.
