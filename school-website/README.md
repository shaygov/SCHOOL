# Стани Богат - Образователна Платформа

Модерна образователна платформа за онлайн курсове, изградена с Next.js, React, TypeScript и PostgreSQL.

## 🚀 Технологии

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS, Framer Motion
- **Backend**: Next.js API Routes
- **Database**: PostgreSQL с Prisma ORM
- **Authentication**: JWT
- **Payments**: Stripe (готово за интеграция)

## 🛠 Инсталация

### Предварителни изисквания:
- Node.js 18.17.1+
- PostgreSQL
- npm или yarn

### 1. Клониране на проекта
```bash
cd /home/ahmed/Desktop/SCHOOL/school-website
```

### 2. Инсталиране на зависимости
```bash
npm install
```

### 3. Настройка на базата данни
```bash
# Създайте PostgreSQL база данни
createdb school_website

# Копирайте env.example в .env и попълнете данните
cp env.example .env
```

### 4. Настройка на Prisma
```bash
# Генериране на Prisma клиент
npx prisma generate

# Мигриране на базата данни
npx prisma migrate dev --name init

# (Опционално) Seed данни
npx prisma db seed
```

### 5. Стартиране на приложението
```bash
npm run dev
```

Приложението ще бъде достъпно на `http://localhost:3000`

## 🗄 База данни

### Основни модели:
- **User**: Потребители (студенти, инструктори, админи)
- **Course**: Курсове
- **Module**: Модули в курсовете
- **Lesson**: Уроци в модулите
- **Enrollment**: Записи за курсове
- **Review**: Ревюта и рейтинги
- **Order**: Поръчки и плащания

## 🔐 Автентификация

Системата използва JWT токени за автентификация:
- Регистрация: `/api/auth/register`
- Вход: `/api/auth/login`
- Изход: `/api/auth/logout`
- Проверка на токен: `/api/auth/me`

## 💳 Плащания

Интеграция с Stripe за:
- Еднократни плащания за курсове
- Абонаментни планове
- Възстановяване на плащания
- Webhook за обработка на събития
