Практическо упражнение - MS Access: Създаване на база данни за библиотека

ЦЕЛ НА УПРАЖНЕНИЕТО

В това упражнение ще създадем база данни за библиотека с 3 основни таблици: Книги, Читатели и Заемания. Ще установим връзки между тях и ще изпълним различни заявки за извличане на данни. Целта е да добием основна представа за работата с MS Access.

1) ПОДГОТОВКА - СЪЗДАВАНЕ НА БАЗА ДАННИ

Стъпка 1: Отваряне на MS Access

  • Стартирайте MS Access
  • Изберете "Blank database" (Празна база данни)
  • Именувайте файла "Библиотека.accdb"
  • Изберете местоположение и натиснете "Create"

Стъпка 2: Планиране на структурата

Анализ на изискванията:

  • Библиотеката има книги с различни автори
  • Читатели могат да заемат книги
  • Трябва да следим кога е заета книга и кога трябва да се върне
  • Искаме да знаем дали книгата е върната

2) СЪЗДАВАНЕ НА ТАБЛИЦА "КНИГИ"

Стъпка 1: Създаване на таблицата

  • В навигационната област натиснете "Create" → "Table Design"
  • Именувайте таблицата "Книги"

  • Преминете към Datasheet View

5) СЪЗДАВАНЕ НА ВРЪЗКИ МЕЖДУ ТАБЛИЦИТЕ

Стъпка 1: Отваряне на Relationships

  • В лентата с инструменти натиснете "Database Tools" → "Relationships"
  • Добавете всички три таблици (Книги, Читатели, Заемания)

Стъпка 2: Установяване на връзките

  • Книги ↔ Заемания: КнигаID (1:N)
  • Читатели ↔ Заемания: ЧитателID (1:N)
Настройки за връзките:
  • Enforce Referential Integrity: ✓
  • Cascade Update Related Fields: ✓
  • Cascade Delete Related Records: ✗

Стъпка 3: Запазване на връзките

  • Запазете схемата на връзките (Ctrl+S)

6) СЪЗДАВАНЕ И ИЗПЪЛНЕНИЕ НА ЗАЯВКИ

Заявка 1: Показване на всички налични книги

Стъпки за създаване:

  • Create → Query Design
  • Добавете таблицата "Книги"
  • Изберете всички полета
  • В критериите за "Налична" въведете "Yes"
SELECT Книги.*
FROM Книги
WHERE Книги.Налична = True;

Заявка 2: Кой читател е заел коя книга

Стъпки за създаване:

  • Create → Query Design
  • Добавете таблиците "Книги", "Читатели", "Заемания"
  • Access автоматично ще установи връзките
  • Изберете полетата: Заглавие, Автор, Име, Фамилия, ДатаЗаемане
SELECT Книги.Заглавие, Книги.Автор, Читатели.Име, Читатели.Фамилия, Заемания.ДатаЗаемане
FROM (Читатели INNER JOIN Заемания ON Читатели.ЧитателID = Заемания.ЧитателID) 
INNER JOIN Книги ON Заемания.КнигаID = Книги.КнигаID
WHERE Заемания.Върната = False;

Заявка 3: Просрочени заемания

Стъпки за създаване:

  • Създайте нова заявка
  • Добавете всички три таблици
  • В критериите за "ДатаВръщане" въведете: < Date()
  • В критериите за "Върната" въведете: False
SELECT Книги.Заглавие, Читатели.Име, Читатели.Фамилия, Заемания.ДатаВръщане
FROM (Читатели INNER JOIN Заемания ON Читатели.ЧитателID = Заемания.ЧитателID) 
INNER JOIN Книги ON Заемания.КнигаID = Книги.КнигаID
WHERE Заемания.ДатаВръщане < Date() AND Заемания.Върната = False;

Заявка 4: Статистика по жанрове

Стъпки за създаване:

  • Създайте нова заявка
  • Добавете само таблицата "Книги"
  • Изберете полето "Жанр"
  • Добавете изчислено поле: CountOfКнигаID: Count(КнигаID)
  • В Query Design натиснете "Totals" за групиране
SELECT Книги.Жанр, Count(Книги.КнигаID) AS CountOfКнигаID
FROM Книги
GROUP BY Книги.Жанр;

7) СЪЗДАВАНЕ НА ФОРМА ЗА ВЪВЕЖДАНЕ

Стъпка 1: Създаване на форма за читатели

  • Create → Form Wizard
  • Изберете таблицата "Читатели"
  • Изберете всички полета
  • Изберете "Columnar" layout
  • Именувайте формата "ФормаЧитатели"

Стъпка 2: Тестване на формата

  • Отворете формата
  • Добавете нов читател
  • Тествайте валидацията на Email полето

8) СЪЗДАВАНЕ НА ОТЧЕТ

Стъпка 1: Създаване на отчет за заемания

  • Create → Report Wizard
  • Изберете таблиците "Книги", "Читатели", "Заемания"
  • Изберете полетата: Заглавие, Автор, Име, Фамилия, ДатаЗаемане, ДатаВръщане
  • Групирайте по "Жанр"
  • Сортирайте по "ДатаЗаемане"
  • Изберете "Tabular" layout
  • Именувайте отчета "ОтчетЗаемания"

9) ТЕСТВАНЕ И ВАЛИДАЦИЯ

Чеклист за тестване:

  • ✓ Всички таблици са създадени правилно
  • ✓ Връзките между таблиците работят
  • ✓ Заявките връщат очакваните резултати
  • ✓ Формата позволява въвеждане на данни
  • ✓ Отчетът се генерира правилно
  • ✓ Валидацията работи (Email формат)
  • ✓ Не можете да изтриете запис с връзки

10) ДОПЪЛНИТЕЛНИ УПРАЖНЕНИЯ

Задача 1: Параметризирана заявка

Създайте заявка, която показва всички книги от определен жанр (параметър).

Задача 2: Макрос за автоматизация

Създайте макрос, който отваря формата за читатели и показва съобщение.

Задача 3: UPDATE заявка

Създайте заявка, която маркира всички просрочени заемания като "трябва да се върнат".
