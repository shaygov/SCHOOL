📘 Квадратен корен. Свойства

Обобщение на темата „Квадратен корен“ — определения, основни свойства и решени задачи от учебника.

🎯 1. Запомнете!

Рационални и ирационални числа

Рационални числа — множеството от цели числа и дроби. Всяко рационално число може да се представи като крайна или безкрайна периодична десетична дроб.

Ирационално число — безкрайна непериодична десетична дроб. Множеството от рационални и ирационални числа образува реалните числа.

Квадратен корен

Квадратният корен от неотрицателно число a ≥ 0 е единственото неотрицателно число, чиято втора степен е равна на a.

√a съществува ⇔ a ≥ 0
√a = x ⇔ x² = a, a ≥ 0, x ≥ 0

Корените от числа, които не са точни квадрати — √2, √3, √5, √6, √7, √8, √10, … — са ирационални числа.

Приближение на √7 = 2,6457513…
• до 0,1: √7 ≈ 2,6
• до 0,01: √7 ≈ 2,65
• до 0,001: √7 ≈ 2,646

📐 2. Основни свойства

Свойство Формула Пример
Квадратен корен от степен √(a²ⁿ) = aⁿ  (a ≥ 0) √(5²) = 5  |  √(7⁴) = 7²
Степенуване на корен (√a)² = a  (a ≥ 0) (√5)² = 5
Корен от произведение √(a·b) = √a · √b √(5·7) = √5 · √7
Произведение от корени √a · √b = √(a·b) √5 · √7 = √(5·7)
Корен от частно √(a/b) = √a / √b  (b > 0) √(5/7) = √5 / √7
Частно от корени √a / √b = √(a/b) √5 / √7 = √(5/7)
Изнасяне на множител √(a²·b) = a√b √27 = √(9·3) = 3√3
Внасяне на множител a√b = √(a²·b) 3√3 = √(9·3) = √27
Сравняване a > b ⇒ √a > √b √10 > √7, защото 10 > 7
⚠️ Важно! Няма правило за коренуване на сбор и разлика:
√(a + b) ≠ √a + √b    и    √(a − b) ≠ √a − √b

✏️ 3. Решени задачи

Задача 1 — Допустими стойности на x

Намерете допустимите стойности на x в корените:

а) √(x − 2)
б) √(x − 7)
в) √(5 − x)
г) √(10 − x)
Решение:
а) x − 2 ≥ 0, x ≥ 2 ⇒ DCₓ: x ∈ [2; +∞)
б) x − 7 ≥ 0, x ≥ 7 ⇒ DCₓ: x ∈ [7; +∞)
в) 5 − x ≥ 0, x ≤ 5 ⇒ DCₓ: x ∈ (−∞; 5]
г) 10 − x ≥ 0, x ≤ 10 ⇒ DCₓ: x ∈ (−∞; 10]

Задача 2 — Разлагане на множители (разлика от квадрати)

Разложете на множители:

а) x² − 2
б) 9x² − 5
в) 3x² − 4
г) 5x² − 7
Решение: използваме a² − b² = (a − b)(a + b)

а) x² − 2 = x² − (√2)² = (x − √2)(x + √2)
б) 9x² − 5 = (3x)² − (√5)² = (3x − √5)(3x + √5)
в) 3x² − 4 = (√3·x)² − 2² = (√3·x − 2)(√3·x + 2)
г) 5x² − 7 = (√5·x)² − (√7)² = (√5·x − √7)(√5·x + √7)

Задача 3 — Разлагане на множители (общ корен)

Разложете на множители:

а) √15 − √6
б) √33 + √21
в) 2√21 − √42
Решение:

а) √15 − √6 = √(5·3) − √(2·3) = √5·√3 − √2·√3 = √3(√5 − √2)
б) √33 + √21 = √(3·11) + √(3·7) = √3·√11 + √3·√7 = √3(√11 + √7)
в) 2√21 − √42 = 2√21 − √(2·21) = 2√21 − √2·√21 = √21(2 − √2)
= √21((√2)² − √2) = √21·√2(√2 − 1) = √42(√2 − 1)

Задача 4 — Съкращаване на дроби

Съкратете дробите:

а) (√75 + √20) / √5
б) (√21 + √12 − √24) / √3
Решение:

а) (√75 + √20) / √5 = (√(5·15) + √(5·4)) / √5 = (√5(√15 + √4)) / √5 = √15 + 2
б) (√21 + √12 − √24) / √3 = (√(3·7) + √(3·4) − √(3·8)) / √3
= (√3(√7 + √4 − √8)) / √3 = √7 + 2 − √8 = √7 + 2 − 2√2 = √7 + 2 − 2√2

Задача 5 — Равенства с √a²

При какви стойности на a са изпълнени равенствата:

а) √(a²) = a
б) √(a²) = −a
Решение:

а) √(a²) = |a|. Равенството √(a²) = a е изпълнено, когато a ≥ 0.
б) √(a²) = −a е изпълнено, когато −a ≥ 0, т.е. a ≤ 0.
