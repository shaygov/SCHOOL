Материали за подготовка за контролно по ООП (12б)

Цел: това кратко ръководство покрива всички теми и формата на въпросите от теста (вж. data.json). Прочетете внимателно и упражнете примерите.

Кратка информация за формата и оценяването

  • Варианти: 2
  • Въпроси на вариант: 9 (въпроси 1–8 имат по 3 празни места; въпрос 9 — 1 празно място)
  • Точки за празно място: 4 точки
  • Повечето въпроси = 12 т. (3 x 4); въпрос 9 = 4 т.
  • Формат: запълване на празни места в C# код (идентификатори, методи, конструкции)

Ключови теми (според критериите)

  • Структурни шаблони: Adapter, Bridge, Composite, Decorator, Facade
  • Използване на интерфейси, композиция и делегиране
  • Създаване чрез фабрики (Abstract Factory, Factory Method, Builder)

Практически подсказки

  • Внимавайте за големи/малки букви — отговорите трябва да съвпадат синтактично.
  • Ако се иска метод в интерфейс — използвайте смислено име (в теста: Operation).
  • При фабрики — очаква се създаване чрез new и извикване на правилния метод (CreateButton, Build и т.н.).

Кратки примери и правила за всяка тема

Singleton (попълване)

public class Logger { private static Logger instance; private Logger() { } public static Logger Instance { get { if (instance == null) instance = new Logger(); return instance; } } }

Очаквани отговори: модификаторите и типа (напр. public, Logger, private).

Builder

class ProductBuilder { private Product product = new Product(); public ProductBuilder SetName(string name) { product.Name = name; return this; } public Product Build() { return product; } }

Очаквани части: връщане на полето (product), името на билдъра и извикване Build().

Prototype

interface IPrototype { IPrototype Clone(); } class Person : IPrototype { public IPrototype Clone() { return (Person)this.MemberwiseClone(); } }

Частите: интерфейсния тип и MemberwiseClone().

Abstract Factory / Factory Method

// Abstract Factory interface IGUIFactory { IButton CreateButton(); } class WinFactory : IGUIFactory { public IButton CreateButton() { return new WinButton(); } }

Търси се правилното използване на new и CreateButton / FactoryMethod.

Composite / Decorator

interface IComp { void Operation(); } class Composite : IComp { private List<IComp> ch = new List<IComp>(); public void Add(IComp c) { ch.Add(c); } public void Operation() { foreach(var c in ch) c.Operation(); } } class Decorator : IComp { protected IComp inner; public Decorator(IComp i) { inner = i; } public void Operation() { inner.Operation(); Console.WriteLine("+D"); } }

В теста ще се попълват името на метода (Operation) и извикванията на Operation().

Facade / Adapter

class Facade { private A a = new A(); private B b = new B(); public void DoWork() { a.A1(); b.B1(); } } class Adapter : INewApi { private Facade f = new Facade(); public void Do() { f.DoWork(); } }
