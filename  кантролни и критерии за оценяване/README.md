Шаблон и валидатор за `rubric` обекти

Файлове:
- `rubric_schema.json` — JSON Schema, която дефинира стандартизираното поле `rubric`.
- `rubric_template.json` — празен/запълнен шаблон, който можете да използвате за нови файлове.
- `validate_rubrics.py` — скрипт за валидиране на всички `data.json` файлове под дадена директория.
- `requirements.txt` — зависимости за валидатора.

Инструкции:
1. Инсталирайте зависимостите:
   pip install -r requirements.txt
2. Стартирайте валидатора от папката `кантролни и критерии за оценяване`:
   python3 validate_rubrics.py --dir .
   По подразбиране скриптът очаква `rubric_schema.json` в същата папка като скрипта.

Изход:
- За всеки `data.json` ще се покаже дали полето `rubric` е валидно или ще се изведат грешките.
