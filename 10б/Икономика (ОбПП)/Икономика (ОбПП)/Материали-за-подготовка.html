1. Мрежови топологии

1.1. Видове топологии

Топология Описание Предимства Недостатъци
Звезда (Star) Всички устройства свързани към централен хъб/комутатор Лесно управление, изолиране на проблеми Зависимост от централното устройство
Шина (Bus) Всички устройства свързани към общ кабел Икономична, лесна за инсталация Проблеми засягат цялата мрежа
Пръстен (Ring) Устройства свързани в кръг, данните се предават в една посока Равномерно разпределение на трафика Проблем спира цялата мрежа
Мрежа (Mesh) Всяко устройство свързано с всяко друго Висока надеждност, резервни пътища Високи разходи, сложна конфигурация

2. Мрежови протоколи

2.1. OSI модел (7 слоя)

  1. Приложен слой (Application) - HTTP, FTP, SMTP, DNS
  2. Слой на представяне (Presentation) - Кодиране, компресия, криптиране
  3. Сесиен слой (Session) - Управление на сесии
  4. Транспортен слой (Transport) - TCP, UDP
  5. Мрежов слой (Network) - IP, маршрутизация
  6. Канален слой (Data Link) - Ethernet, MAC адреси
  7. Физически слой (Physical) - Кабели, сигнали

2.2. Основни протоколи

Протокол Пълно име Функция Порт
HTTP HyperText Transfer Protocol Предаване на уеб страници 80
HTTPS HTTP Secure Шифрован HTTP 443
TCP Transmission Control Protocol Надежден пренос на данни -
UDP User Datagram Protocol Бърз пренос без гаранции -
FTP File Transfer Protocol Трансфер на файлове 21
SMTP Simple Mail Transfer Protocol Изпращане на имейл 25
POP3 Post Office Protocol v3 Изтегляне на имейл 110
DNS Domain Name System Превод на имена към IP адреси 53
DHCP Dynamic Host Configuration Protocol Автоматично раздаване на IP адреси 67/68

Разлика между TCP и UDP:

  • TCP: Надежден, с потвърждения, подреждане на пакети, управление на потока. Използва се за: уеб браузъри, имейл, файлов трансфер.
  • UDP: Бърз, без гаранции, без установяване на връзка. Използва се за: видео стрийминг, онлайн игри, DNS заявки.

3. Мрежови операционни системи

3.1. Какво е мрежова операционна система (NOS)?

Мрежовата операционна система е специализирана ОС, проектирана да управлява мрежови ресурси и да осигурява услуги на мрежовите клиенти.

3.2. Основни функции на NOS

  • Управление на потребители и групи - Централизирана автентикация и авторизация
  • Управление на файлове и принтери - Споделяне на ресурси
  • Директория услуги - Active Directory (Windows), LDAP
  • Мрежова сигурност - Firewall, VPN, шифроване
  • Резервно копие и възстановяване - Автоматични backup системи
  • Мониторинг и управление - Проследяване на производителността

3.3. Примери за мрежови ОС

  • Windows Server - Microsoft сървърна ОС с Active Directory
  • Linux сървърни дистрибуции - Ubuntu Server, CentOS, Red Hat
  • Novell NetWare - Историческа NOS (вече не се поддържа)
  • Unix сървъри - AIX, Solaris

4. Мрежова сигурност. Компютърни вируси

4.1. Видове зловреден софтуер (Malware)

Тип Описание Характеристики
Вирус Зловреден код, който се прикрепя към файлове Нуждае се от носител, се размножава
Червей (Worm) Самостоятелно се разпространява по мрежата Не нуждае носител, бързо разпространение
Trojan Horse Прикрива се като легитимен софтуер Не се размножава, но отваря backdoor
Ransomware Криптира данни и изисква откуп Блокира достъп до файлове
Spyware Събира информация без знанието на потребителя Скрито наблюдение
Adware Показва нежелани реклами По-малко опасен, но досаден

4.2. Мерки за защита

  • Антивирусен софтуер - Регулярни сканирания и актуализации
  • Firewall - Филтриране на входящ и изходящ трафик
  • Регулярни актуализации - Пачове за ОС и софтуер
  • Силни пароли - Сложни пароли и многофакторна автентикация
  • Резервни копия - Регулярни backup-и на важни данни
  • Обучение на потребителите - Разпознаване на фишинг и подозрителни имейли

Фишинг (Phishing)

Фишинг е опит за получаване на лична информация чрез фалшиви имейли или уебсайтове, които приличат на легитимни. Винаги проверявайте:

  • Домейна на подателя
  • URL адресите преди кликване
  • Граматиката и правописа
  • Не споделяйте пароли или лични данни

6. URL, HTTP, HTML, XML

6.1. URL (Uniform Resource Locator)

URL е адрес, който идентифицира ресурс в интернет.

Пример: https://www.example.com/path/page.html?param=value#section
  • https:// - Протокол
  • www.example.com - Домейн име
  • /path/page.html - Път до ресурса
  • ?param=value - Параметри
  • #section - Яко (anchor)

6.2. HTTP (HyperText Transfer Protocol)

Протокол за предаване на уеб страници и други ресурси в интернет.

  • HTTP - Нешифрован (порт 80)
  • HTTPS - Шифрован с TLS/SSL (порт 443)
HTTP методи:
  • GET - Извличане на ресурс
  • POST - Изпращане на данни
  • PUT - Актуализиране на ресурс
  • DELETE - Изтриване на ресурс

6.3. HTML (HyperText Markup Language)

Език за маркиране, използван за създаване на уеб страници.

<html>
  <head>
    <title>Заглавие</title>
  </head>
  <body>
    <h1>Заглавие</h1>
    <p>Параграф с текст</p>
  </body>
</html>

6.4. XML (eXtensible Markup Language)

Език за маркиране, използван за структуриране и съхранение на данни.

<?xml version="1.0" encoding="UTF-8"?>
<student>
  <name>Иван Иванов</name>
  <grade>12а</grade>
</student>

7. WWW, WEB сървър, WEB клиент

7.1. WWW (World Wide Web)

WWW е система от взаимосвързани документи и ресурси, достъпни чрез интернет.

  • Създаден от Тим Бърнърс-Лий през 1989 г.
  • Базиран на HTTP протокол и HTML език
  • Използва URL адреси за идентификация на ресурси

7.2. WEB сървър

Компютърна програма или система, която доставя уеб страници на клиенти.

  • Функции: Приема HTTP заявки, обработва ги, изпраща отговори
  • Примери за софтуер: Apache, Nginx, Microsoft IIS
  • Статични страници: Предварително създадени HTML файлове
  • Динамични страници: Генерирани от сървърни скриптове (PHP, Python, Node.js)

7.3. WEB клиент

Приложение (браузър), което заявява и показва уеб страници.

  • Функции: Изпраща HTTP заявки, получава и рендира HTML/CSS/JavaScript
  • Примери: Chrome, Firefox, Safari, Edge
  • Процес: Потребител въвежда URL → Браузър изпраща заявка → Сървър отговаря → Браузър показва страницата

8. Машини за търсене

8.1. Какво е машина за търсене?

Система за търсене на информация в интернет чрез ключови думи.

8.2. Как работи?

  1. Индексиране (Crawling) - Автоматично обхождане на уебсайтове
  2. Индексиране (Indexing) - Създаване на индекс от думи и страници
  3. Търсене (Searching) - Съвпадение на заявката с индекса
  4. Ранжиране (Ranking) - Подреждане на резултатите по релевантност

8.3. Популярни машини за търсене

  • Google - Най-популярната в света
  • Bing - Microsoft търсачка
  • Yahoo - Историческа търсачка
  • DuckDuckGo - Фокус върху поверителността

9. Метасредства за търсене

9.1. Какво е метасредство за търсене?

Система, която търси в множество машини за търсене едновременно и комбинира резултатите.

9.2. Предимства

  • По-широк обхват на резултатите
  • Сравнение между различни търсачки
  • Единна точка за достъп
  • Възможност за филтриране и сортиране

9.3. Примери

  • Dogpile - Комбинира резултати от Google, Yahoo, Bing
  • Metacrawler - Един от първите мета-търсачки
  • Search.com - Мета-търсачка с различни категории

Разлика между машина за търсене и метасредство:

  • Машина за търсене: Има собствен индекс, обхожда уебсайтове
  • Метасредство: Няма собствен индекс, използва резултати от други търсачки
