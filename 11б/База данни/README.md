# 11б · Бази данни — Supabase урок

Тема: "Създаване на бази от данни с SQL. Създаване на таблици без връзки между тях. Задаване на първичен ключ"

## Какво ще направим
- Създаваме база в Supabase (PostgreSQL)
- Създаваме две таблици без връзки: `students`, `courses`
- Добавяме първични ключове (PRIMARY KEY) с UUID
- Вмъкваме и преглеждаме записи през Supabase Dashboard

## Защо Supabase?
- Модерна cloud база данни с PostgreSQL
- Безплатен план с 500MB база данни
- Удобен уеб интерфейс за изпълнение на SQL
- Автоматични backup-и и сигурност
- Подходящо за учебна среда, няма нужда от инсталация

## Инсталация и стартиране
1. Създайте безплатен акаунт в Supabase: https://supabase.com
2. Създайте нов проект в Supabase Dashboard
3. Отворете SQL Editor в проекта си

## Изпълнение на подготвения SQL
1. От Supabase Dashboard отворете SQL Editor
2. Отворете файла `complete_school_database_supabase.sql` и копирайте съдържанието
3. Поставете в SQL Editor и натиснете Run
4. Проверете резултата в Table Editor

Файлът създава:
- Таблица `students` с колони: `id` (UUID PK), `first_name`, `last_name`, `email (UNIQUE)`, `created_at`
- Таблица `courses` с колони: `id` (UUID PK), `title`, `description`, `created_at`
- Примерни записи и примерни заявки `SELECT`
- Row Level Security (RLS) политики

## Практически задачи
- Вмъкнете през Table Editor минимум 3 ученици и 2 курса
- Потърсете ученици по фамилия с SQL заявки
- Тествайте сортиране с ORDER BY

## Типични грешки и решения
- Error: „syntax error" → проверете дали използвате PostgreSQL синтаксис
- UUID грешки → използвайте `uuid_generate_v4()` за нови записи
- RLS грешки → политиките позволяват всички операции за урока
