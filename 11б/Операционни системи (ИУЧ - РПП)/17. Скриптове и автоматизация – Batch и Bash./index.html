Въведение

Скриптовете автоматизират повтарящи се задачи: архивиране, мониторинг, деплой, поддръжка. Този урок разглежда основите на Windows Batch (.bat/.cmd) и Unix Bash (.sh), с практически примери и методи за график и добри практики.

Batch (Windows)

Batch скриптовете са прости и широко поддържани в Windows. Подходящи са за административни задачи и интеграция със стари инструменти.

Синтаксис и основи

  • Деактивиране на ехо: @echo off
  • Променливи: set NAME=VALUE, четене: %NAME%
  • Условни изрази: if /i "%VAR%"=="value" ( ... )
  • Цикли: for %%i in (*.txt) do echo %%i

Пример: Архивиране и ротация на архиви (Batch)

@echo off
rem Backup folder and keep last 7 archives
setlocal enabledelayedexpansion
set SRC=C:\Users\Public\Documents\MyProject
set DST_DIR=C:\Backups\MyProject
if not exist "%DST_DIR%" mkdir "%DST_DIR%"
set DATE=%DATE:~10,4%-%DATE:~4,2%-%DATE:~7,2%
set DST=%DST_DIR%\backup-%DATE%.zip
powershell -Command "Compress-Archive -Path '%SRC%\\*' -DestinationPath '%DST%'"
rem Keep only last 7 files
for /f "skip=7 delims=" %%f in ('dir /b /o:-d "%DST_DIR%\backup-*.zip"') do del "%DST_DIR%\%%f"
endlocal

Забележка: За удобство използвайте PowerShell за архивиране и работа с JSON/HTTP.

Bash (Linux / macOS)

Bash е по-гъвкав и мощен за сложни автоматизации. Поддържа функции, pipe-ове, подсистеми и добри практики за надеждност.

Безопасни опции

Добавяйте следните редове в началото на скриптовете за надеждност:

#!/usr/bin/env bash
set -euo pipefail
IFS=$'\n\t'

Пример: Архивиране и ротация (Bash)

#!/usr/bin/env bash
set -euo pipefail
IFS=$'\n\t'

SRC="$HOME/projects/myproject"
DST_DIR="$HOME/backups"
mkdir -p "$DST_DIR"
DST="$DST_DIR/myproject-$(date +%Y-%m-%d).tar.gz"
tar -czf "$DST" -C "$SRC" .
# keep last 7 backups
ls -1t "$DST_DIR"/myproject-*.tar.gz | tail -n +8 | xargs -r rm --

Функции и парсване на аргументи

Използвайте функции за чист код и getopts за опции:

usage(){ echo "Usage: $0 -d DIR -n NAME"; exit 1; }
while getopts ":d:n:" opt; do
  case $opt in
    d) DIR="$OPTARG" ;;
    n) NAME="$OPTARG" ;;
    *) usage ;;
  esac
done

Планиране и автоматично стартиране

Windows — Task Scheduler

Създайте задача (Create Basic Task) или използвайте schtasks.exe за скриптове:

schtasks /Create /SC DAILY /TN "DailyBackup" /TR "C:\Backups\backup.bat" /ST 02:00

Linux — cron

Редактирайте crontab с crontab -e и добавете израз:

# Изпълнява backup.sh всеки ден в 02:00
0 2 * * * /home/username/scripts/backup.sh >> /home/username/logs/backup.log 2>&1

systemd timers (алтернатива на cron)

systemd timers предлагат по-фин контрол и логиране:

/etc/systemd/system/backup.service
[Unit]
Description=Run backup script

[Service]
Type=oneshot
ExecStart=/home/username/scripts/backup.sh

# /etc/systemd/system/backup.timer
[Unit]
Description=Run backup daily

[Timer]
OnCalendar=daily

[Install]
WantedBy=timers.target

Добри практики

  • Логирайте stdout и stderr във файлове и ротационни логове.
  • Не поставяйте пароли в скриптове — използвайте секрет мениджър или environment variables.
  • Използвайте проверка на грешки (exit codes) и изключения.
  • Разделяйте логика във функции и използвайте конфигурационни файлове.
  • Добавете коментари само когато е необходимо — обяснете "защо", не "как".

Упражнения

  1. Напишете Batch скрипт, който архивира дадена директория и запазва само последните 7 архива.
  2. Напишете Bash скрипт, който следи дали процес (по име) работи; ако не — стартира го и записва в лог.
  3. Настройте cron или systemd timer да изпълнява скрипта от упражнение 2; добавете лог ротация.
  4. Разширено: добавете верифициране на бекъпа (checksum) и изпращане на известие при грешка (email или webhook).
