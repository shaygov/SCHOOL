Конзолни команди. Работа с файлове и директории

1. Въведение в конзолата

Конзолата (терминалът) е текстов интерфейс за работа с компютъра. Чрез команди можем да управляваме файлове, директории и програми без да използваме графичен интерфейс.

Как да отворим конзола:

  • Windows: Натисни Win + R, напиши cmd или powershell и натисни Enter
  • Linux: Натисни Ctrl + Alt + T или намери "Terminal" в менюто
  • macOS: Отвори "Terminal" от Applications → Utilities

2. Навигиране (движение) в директории

Основни команди за навигиране:

Преди да работим с файлове, трябва да знаем къде сме и как да се движим между директориите.

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Покажи текущата директория cd pwd pwd
Промени директория cd име_на_директория cd име_на_директория cd име_на_директория
Отиди една директория нагоре cd .. cd .. cd ..
Отиди в главната директория cd \ cd \ cd /
Отиди в домашната директория cd %USERPROFILE% cd ~ cd ~
Покажи съдържанието на директория dir ls или dir ls

Примери за навигиране:

# Windows (CMD)
C:\Users\Иван> cd Documents
C:\Users\Иван\Documents> cd ..
C:\Users\Иван> cd \Windows
C:\Windows>

# Linux/macOS
user@computer:~$ cd Documents
user@computer:~/Documents$ cd ..
user@computer:~$ cd /home/user
user@computer:~$

Важно:

  • В Windows използваме обратна наклонена черта \ за пътища
  • В Linux/macOS използваме права наклонена черта / за пътища
  • В PowerShell можем да използваме и двете
  • За да видим скрити файлове в Linux: ls -a

3. Създаване на директории

Команди за създаване на директории:

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Създай една директория mkdir име_на_директория mkdir име_на_директория mkdir име_на_директория
Създай няколко директории mkdir dir1 dir2 dir3 mkdir dir1, dir2, dir3 mkdir dir1 dir2 dir3
Създай вложени директории mkdir dir1\dir2\dir3 mkdir -p dir1/dir2/dir3 mkdir -p dir1/dir2/dir3

Примери:

# Създаване на проста директория
mkdir МоиДокументи

# Създаване на вложена структура (Linux/PowerShell)
mkdir -p Проекти/2024/Януари

# Windows CMD - трябва да създадеш всяка директория отделно
mkdir Проекти
cd Проекти
mkdir 2024
cd 2024
mkdir Януари

4. Създаване на файлове

Команди за създаване на файлове:

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Създай празен файл type nul > файл.txt New-Item файл.txt или ni файл.txt touch файл.txt
Създай файл с текст echo текст > файл.txt "текст" > файл.txt echo "текст" > файл.txt
Добави текст към файл echo текст >> файл.txt "текст" >> файл.txt echo "текст" >> файл.txt

Примери:

# Създаване на празен файл
# Windows CMD:
type nul > документ.txt

# Windows PowerShell:
New-Item документ.txt

# Linux/macOS:
touch документ.txt

# Създаване на файл с текст
# Windows CMD:
echo Здравей свят > hello.txt

# Windows PowerShell:
"Здравей свят" > hello.txt

# Linux/macOS:
echo "Здравей свят" > hello.txt

5. Копиране на файлове и директории

Команди за копиране:

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Копирай файл copy файл.txt ново_име.txt Copy-Item файл.txt ново_име.txt или cp файл.txt ново_име.txt cp файл.txt ново_име.txt
Копирай файл в друга директория copy файл.txt C:\ДругаДиректория\ Copy-Item файл.txt C:\ДругаДиректория\ cp файл.txt /home/user/ДругаДиректория/
Копирай директория рекурсивно xcopy директория нова_директория /E /I Copy-Item -Recurse директория нова_директория cp -r директория нова_директория
Копирай всички файлове copy *.* C:\Дестинация\ Copy-Item *.* C:\Дестинация\ cp *.* /home/user/Дестинация/

Примери:

# Копиране на файл
# Windows CMD:
copy документ.txt копие.txt

# Windows PowerShell:
Copy-Item документ.txt копие.txt

# Linux/macOS:
cp документ.txt копие.txt

# Копиране на директория с всичко в нея
# Windows CMD:
xcopy МояПроект Резервно /E /I

# Windows PowerShell:
Copy-Item -Recurse МояПроект Резервно

# Linux/macOS:
cp -r МояПроект Резервно

6. Преименуване на файлове и директории

Команди за преименуване:

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Преименувай файл ren старо_име.txt ново_име.txt Rename-Item старо_име.txt ново_име.txt или ren старо_име.txt ново_име.txt mv старо_име.txt ново_име.txt
Преименувай директория ren СтараДиректория НоваДиректория Rename-Item СтараДиректория НоваДиректория mv СтараДиректория НоваДиректория

Примери:

# Преименуване на файл
# Windows CMD:
ren документ.txt нов_документ.txt

# Windows PowerShell:
Rename-Item документ.txt нов_документ.txt

# Linux/macOS:
mv документ.txt нов_документ.txt

# Преименуване на директория
# Windows CMD:
ren СтараПапка НоваПапка

# Windows PowerShell:
Rename-Item СтараПапка НоваПапка

# Linux/macOS:
mv СтараПапка НоваПапка

7. Местене на файлове и директории

Команди за местене:

Местенето е като копиране + изтриване на оригинала. В Linux/macOS командата mv се използва и за преименуване, и за местене.

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Премести файл move файл.txt C:\ДругаДиректория\ Move-Item файл.txt C:\ДругаДиректория\ или mv файл.txt C:\ДругаДиректория\ mv файл.txt /home/user/ДругаДиректория/
Премести директория move Директория C:\НовоМясто\ Move-Item Директория C:\НовоМясто\ mv Директория /home/user/НовоМясто/
Премести всички файлове move *.txt C:\Дестинация\ Move-Item *.txt C:\Дестинация\ mv *.txt /home/user/Дестинация/

Примери:

# Преместване на файл
# Windows CMD:
move документ.txt C:\Documents\

# Windows PowerShell:
Move-Item документ.txt C:\Documents\

# Linux/macOS:
mv документ.txt ~/Documents/

# Преместване на директория
# Windows CMD:
move МояПроект C:\Projects\

# Windows PowerShell:
Move-Item МояПроект C:\Projects\

# Linux/macOS:
mv МояПроект ~/Projects/

8. Изтриване на файлове и директории

Внимание!

Изтриването в конзолата обикновено е необратимо! Файловете не отиват в кошчето, а се изтриват завинаги. Бъди внимателен!

Команди за изтриване:

Действие Windows (CMD) Windows (PowerShell) Linux/macOS
Изтрий файл del файл.txt Remove-Item файл.txt или rm файл.txt rm файл.txt
Изтрий директория (празна) rmdir директория Remove-Item директория или rmdir директория rmdir директория
Изтрий директория с всичко в нея rmdir /S директория Remove-Item -Recurse директория или rm -r директория rm -r директория
Изтрий всички файлове del *.txt Remove-Item *.txt rm *.txt

Примери:

# Изтриване на файл
# Windows CMD:
del документ.txt

# Windows PowerShell:
Remove-Item документ.txt

# Linux/macOS:
rm документ.txt

# Изтриване на директория с всичко в нея
# Windows CMD:
rmdir /S СтараДиректория

# Windows PowerShell:
Remove-Item -Recurse СтараДиректория

# Linux/macOS:
rm -r СтараДиректория

Допълнителни команди:

Действие Windows (CMD) Windows (PowerShell) Linux/macOS

10. Практически примери

Сценарий 1: Създаване на структура за проект

# Windows PowerShell / Linux/macOS
mkdir -p МойПроект/{Документи,ИзходенКод,Изображения}
cd МойПроект
echo "# Мой проект" > README.txt
cd ИзходенКод
touch main.py
cd ../..

# Windows CMD
mkdir МойПроект
cd МойПроект
mkdir Документи ИзходенКод Изображения
echo # Мой проект > README.txt
cd ИзходенКод
type nul > main.py
cd ..\..

Сценарий 2: Организиране на файлове

# Преместване на всички .txt файлове в папка "Текстове"
# Windows PowerShell / Linux/macOS
mkdir Текстове
mv *.txt Текстове/

# Windows CMD
mkdir Текстове
move *.txt Текстове\

Сценарий 3: Резервно копие

# Създаване на резервно копие на директория
# Windows PowerShell
Copy-Item -Recurse МояПроект МояПроект_Резервно

# Linux/macOS
cp -r МояПроект МояПроект_Резервно

# Windows CMD
xcopy МояПроект МояПроект_Резервно /E /I

11. Съвети и добри практики

Важни съвети:

  • Винаги проверявай пътя - използвай pwd или cd преди да изпълниш команда
  • Използвай Tab за автодопълване - натискай Tab за автоматично допълване на имената
  • Бъди внимателен с изтриването - файловете изтрити от конзолата не отиват в кошчето
  • Използвай пълни пътища когато не си сигурен къде си
  • Тествай командите с неважни файлове преди да ги използваш за важни данни

Кратки пътища (wildcards):

  • * - замества всякакви символи (напр. *.txt = всички .txt файлове)
  • ? - замества един символ (напр. file?.txt = file1.txt, file2.txt, но не file10.txt)
  • .. - родителска директория
  • . - текуща директория
  • ~ - домашна директория (Linux/PowerShell)

  • В CMD командите са различни, но логиката е същата
  • Винаги проверявай къде си преди да изпълниш команда
  • Използвай Tab за автодопълване на имена
  • Бъди внимателен с изтриването - то е необратимо!
