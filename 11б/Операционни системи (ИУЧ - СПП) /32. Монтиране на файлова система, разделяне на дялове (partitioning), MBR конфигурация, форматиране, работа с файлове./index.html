Монтиране на файлова система (mount), дялове (partitions), MBR, форматиране (formatting)

11б клас · Операционни системи (ИУЧ – СПП) · Урок 32

🏢 Аналогия: етажна сграда

Хард дискът е като сграда:

  • Разделяне на дялове (partitioning) = строиш отделни етажи (C:, D:, /home)
  • MBR (Master Boot Record) / GPT (GUID Partition Table) = таблото на входа — казва къде е всеки етаж и откъде започва асансьорът (boot)
  • Форматиране (formatting) = обзавеждаш етажа по правила (NTFS, ext4, FAT32)
  • Монтиране (mounting) = отваряш вратата — етажът става достъпен за хора (файлове)

1. Разделяне на дялове (partitioning)

Дял (partition) е логическа част от физическия диск (disk). Един диск може да има няколко дяла — всеки с отделна файлова система (file system).

Защо? За да отделиш Windows от данни, да сложиш Linux до Windows, или да резервираш място за възстановяване.

Тип дял (partition type)Какво еПример
Основен дял (primary partition) Нормален дял, от който може да се стартира ОС C:, Linux /
Разширен дял (extended partition) „Контейнер“ за логически дялове (logical partitions) — само при MBR Рядко се ползва днес
EFI / системен дял (EFI System Partition) Малък дял за зареждане (boot) при UEFI ~100–500 MB, FAT32

Windows — как да видиш дяловете:

  • Win + R → diskmgmt.msc → „Управление на дискове“
  • Виждаш цветни ленти: синьо = основен дял, зелено = логически
  • Десен бутон върху неразпределено пространство → Нов прост том (създаваш дял)

Ubuntu — преглед на дялове:

$ lsblk
NAME   SIZE TYPE MOUNTPOINT
sda    500G disk
├─sda1  200G part /          ← основен дял (система)
├─sda2  280G part /home      ← отделен дял за данни
└─sda3   20G part            ← swap (размяна)

$ sudo fdisk -l /dev/sda    ← подробна таблица на дяловете

2. MBR конфигурация (Master Boot Record)

MBR (Master Boot Record — главен запис за зареждане) е първите 512 байта на диска. Съдържа:

  • Зареждащ натоварвач (boot loader) — малка програма, която стартира ОС
  • Таблица на дялове (partition table) — до 4 основни дяла (primary partitions)
  • Магическо число (signature) 0x55AA — маркер, че дискът е bootable (зареждаем)

MBR (Master Boot Record) vs GPT (GUID Partition Table) — кратко:

  • MBR (Master Boot Record) — по-стар стандарт; макс. 4 основни дяла; дискове до 2 TB
  • GPT (GUID Partition Table) — модерен (UEFI); неограничен брой дялове; дискове над 2 TB
  • Новите компютри с Windows 10/11 обикновено ползват GPT, но MBR все още се среща на по-стари машини
Пример: Лаптоп с Windows 11 и диск 1 TB → почти сигурно е GPT. Стар компютър с Windows 7 и диск 500 GB → вероятно MBR. В „Управление на дискове“ при GPT първият дял е „EFI System Partition“.

3. Форматиране (formatting)

Форматирането (formatting) създава файлова система (file system) върху дял. Без форматиране дялът е просто „неразпределено пространство (unallocated space)“ — няма папки, няма файлове.

Важно: Създаването на дял (partitioning) и форматирането (formatting) са различни стъпки!

Създаване на дял (partitioning) → Форматиране (formatting) → Монтиране (mounting) (разделяш диска) (слагаш NTFS/ext4) (отваряш за ползване) [████████|░░░░░░] [████████|░░░░░░] C: и D: готови дял 1 празно NTFS (празен) за копиране на файлове
Файлова система (file system)КъдеЗа какво
NTFSWindowsСистемен дял C:, големи файлове, права
FAT32 / exFATUSB, SDУниверсална съвместимост
ext4Linux/UbuntuСтандарт за Linux дялове

Windows — форматиране на USB флашка:

  1. Вкарваш USB → File Explorer → десен бутон върху устройството
  2. Форматиране… → избираш NTFS (големи файлове) или FAT32 (съвместимост)
  3. Старт → всички данни на флашката се изтриват!

Ubuntu — форматиране на дял (пример):

# Форматиране на /dev/sdb1 с ext4
$ sudo mkfs.ext4 /dev/sdb1

# Форматиране на USB с FAT32
$ sudo mkfs.vfat -F 32 /dev/sdc1
⚠️ Внимание: Форматирането изтрива всички данни на дяла! Винаги проверявай дали си избрал правилното устройство (/dev/sdb1, не /dev/sda1).

4. Монтиране на файлова система (mounting)

Монтирането (mounting) „закачва“ форматиран дял към дървото на файловете (file tree), за да можеш да четеш и записваш файлове.

Без монтиране ОС вижда устройството, но не можеш да работиш с файлове в него.

🪟 Windows

  • Автоматично монтиране (auto mount) → буква на диск (drive letter): C:, D:, E:
  • USB флашка → обикновено E: или F:
  • Размонтиране (unmount): Безопасно изваждане на хардуер (Safely Remove Hardware)

🐧 Ubuntu / Linux

  • Дялът е устройство: /dev/sda1, /dev/sdb1
  • Монтира се в точка на монтиране (mount point): /, /home, /media/usb
  • Размонтиране (unmount): umount или „Safely Remove“

Ubuntu — ръчно монтиране и преглед:

# Кои файлови системи са монтирани и колко място имат
$ df -h
Файлова система  Размер  Използвано  Свободно  Монтирана на
/dev/sda2         234G     45G        178G      /
/dev/sdb1          16G      8G          8G       /media/ahmed/USB

# Ръчно монтиране (ако не е автоматично)
$ sudo mkdir -p /mnt/usb
$ sudo mount /dev/sdb1 /mnt/usb

# Размонтиране (преди да извадиш USB!)
$ sudo umount /mnt/usb

Windows — преглед на монтираните дялове:

  • File Explorer → „Този компютър“ → виждаш C:, D:, USB
  • Win + R → diskmgmt.msc → колона „Състояние“ показва дали дялът е Healthy
Пример от живота: Вкарваш USB в Windows — веднага виждаш E:\. Копираш файл, после кликваш „Безопасно изваждане“. В Ubuntu същата флашка се появява в /media/потребител/ИМЕ. Ако я извадиш без umount, файлът може да се повреди.

5. Работа с файлове (working with files)

След монтиране (mounting) работиш с файлове (files) и папки/директории (folders / directories) — през графичен интерфейс (GUI) или команди.

5.2. Команди (Ubuntu)

# Навигация
$ pwd                          # къде съм
$ ls -la                       # списък файлове (с детайли)
$ cd /home/student/Documents   # влизане в папка

# Създаване и копиране
$ mkdir projekt                # нова папка
$ touch domashno.txt           # празен файл
$ cp domashno.txt backup/      # копиране
$ mv stari.txt novi.txt        # преименуване / местене
$ rm domashno.txt              # изтриване

# Преглед на съдържание
$ cat domashno.txt             # показва текста
$ less golям_файл.log          # преглед на голям файл (q за изход)

6. Цялостен процес: от нов диск до файлове

  1. Физически диск (physical disk) — поставяш HDD/SSD/USB в компютъра
  2. Разделяне на дялове (partitioning) — Disk Management / fdisk, gparted
  3. MBR / GPT — таблицата на дялове (partition table) се записва в началото на диска
  4. Форматиране (formatting) — всеки дял получава файлова система (NTFS, ext4, FAT32)
  5. Монтиране (mounting) — дялът става достъпен (C: или /home)
  6. Работа с файлове (working with files) — създаваш, копираш, изтриваш

7. Запомни накратко

  • 📀 Дял (partition) = логическа част от диска · форматиране (formatting) = слагаш файлова система · монтиране (mounting) = отваряш за ползване
  • 📋 MBR (Master Boot Record) = 512 байта в началото; boot loader + partition table с 4 дяла · GPT (GUID Partition Table) = модерен вариант за големи дискове
  • 🪟 Windows: C:, D: · автоматично монтиране (auto mount) · diskmgmt.msc
  • 🐧 Ubuntu: /dev/sda1 → / или /media/... · df -h, mount, umount
  • ⚠️ Форматирането (formatting) изтрива данни · преди изваждане на USB — размонтиране (unmount)!

Връзка с предишен урок: Файловата система (file system) — NTFS, ext4, FAT32 — определя как се пазят файловете. Дялът (partition), MBR/GPT и монтирането (mounting) определят къде и кога тази система е достъпна за потребителя.
